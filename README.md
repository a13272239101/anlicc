## 二、青龙面板详细设置

### 1. 上传脚本文件

将以下脚本文件上传至青龙面板的指定目录（通常为`scripts`文件夹），可根据反编译需求选择组合：



| 脚本文件      | 作用                | 可选性 | 反编译难度   |
| --------- | ----------------- | --- | ------- |
| `main.py` | 主任务入口文件，负责启动与任务调度 | 必选  | 低（源码文件） |
| `run.py`  | 核心执行脚本，包含业务逻辑     | 可选  | 低（源码文件） |
| `run.pyd` | 编译后的执行脚本，保护源码     | 可选  | 中       |
| `run.so`  | 编译后的执行脚本，更高程度保护源码 | 可选  | 高       |

**推荐组合**：



*   追求易用性：`main.py``  +  ``run.py`（便于修改调试）

*   追求安全性：`main.py`` + run.pyd` 或 `main.py``  +  ``run.so`（防止源码泄露）

### 2. 配置环境变量

进入青龙面板 → 左侧菜单栏「环境变量」→ 点击「创建」，按以下表格填写参数，确保必填项完整无误：



| 备注        | 参数名                 | 是否必填 | 参数值示例                   | 说明                                     |
| --------- | ------------------- | ---- | ----------------------- | -------------------------------------- |
| 服务器地址     | `anlicc_server_url` | 是    | `http://127.0.0.1:3000` | 填写部署卡密后端的服务器地址（IP + 端口），确保青龙能访问该地址     |
| COOKIE 数据 | `anlicc_xf`         | 是    | （需按「第三章格式」填写）           | 存储账号的 cookie 信息，是脚本执行的核心凭证             |
| 授权卡密      | `anlicc_XFKami`     | 是    | `Ka123456`              | 从卡密后端获取的授权码，用于验证脚本使用权限                 |
| 线程数       | `anlicc_XF_thread`  | 否    | `20`                    | 控制脚本并发执行的线程数量，默认值为 20，可根据服务器性能调整       |
| 金币上限数量    | `anlicc_XF_limit`   | 否    | `150000`                | 设定账号金币获取的上限值，默认 150000，超出后脚本停止该账号的金币任务 |

## 三、Cookie 账号数据格式

Cookie 数据需按固定格式组织，使用 \*\*`@`符号 \*\* 将内容分为 5 段，缺一不可，格式如下：



```
备注@COOKIE数据@message@sua@bua@ua@socks5h代理
```



| 字段         | 说明                           | 示例                                                                                                                |
| ---------- | ---------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 备注         | 用于区分账号，如账号昵称、用途等             | `测试账号1`                                                                                                           |
| COOKIE 数据  | 账号的完整 Cookie 信息（从浏览器或抓包工具获取） | `sessionid=123456;uid=789`                                                                                        |
| message    | 预留字段，根据脚本需求填写（无需求可填`空`）      | `空`                                                                                                               |
| sua        | 设备相关参数（通常从抓包工具获取）            | `Windows NT 10.0; Win64; x64`                                                                                     |
| bua        | 浏览器相关参数（通常从抓包工具获取）           | `Chrome/112.0.0.0`                                                                                                |
| ua         | User-Agent 参数（通常从抓包工具获取）     | `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/112.0.0.0 Safari/537.36` |
| socks5h 代理 | 该账号对应的代理地址（需符合「第四章格式」）       | `127.0.0.1#1080#user#pass`                                                                                        |

**完整示例**：



```
测试账号1@sessionid=123456;uid=789@空@Windows NT 10.0; Win64; x64@Chrome/112.0.0.0@Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/112.0.0.0 Safari/537.36@127.0.0.1#1080#user#pass
```

## 四、socks5h 代理格式

socks5h 代理需使用 \*\*`#`或`|`符号 \*\* 将内容分为 4 段，格式如下（两种分隔符二选一，不可混用）：

### 格式 1（使用`#`分隔）



```
代理IP#代理端口#代理账号（无则留空）#代理密码（无则留空）
```

### 格式 2（使用`|`分隔）



```
代理IP|代理端口|代理账号（无则留空）|代理密码（无则留空）
```

**示例**：



*   有账号密码的代理：`127.0.0.1#1080#user123#pass456` 或 `127.0.0.1``|1080|user123|pass456`

*   无账号密码的代理：`192.168.1.1#1081##` 或 `192.168.1.1``|1081||`

## 五、关键注意事项与常见问题

### 1. 接口与密码配置



*   **接口 IP 替换**：对接卡密后端时，需将接口文档中的默认 IP 替换为**自己服务器的公网 IP**，确保 API 请求能正确指向后端。

*   **管理员密码修改**：部署卡密后端后，务必修改管理员密码！密码存储在`server.py`文件的`ADMIN_TOKEN=""`字段中，示例：`ADMIN_TOKEN="MyNewPass123"`（建议包含大小写字母、数字及特殊符号，提高安全性）。

### 2. 常见问题：代理设置后提示 “未加白名单”

#### 问题现象

配置 socks5h 代理后，脚本运行报错，提示 “设置了代理但未加白名单”。

#### 问题原因

代理服务商开启了 IP 白名单限制，当前使用的服务器 IP（青龙面板 / Windows 服务器的公网 IP）未添加到代理的白名单中，导致代理无法正常连接。

#### 解决步骤



1.  确认当前服务器的公网 IP（可通过`https://www.ip138.com/`等工具查询）；

2.  登录代理服务商的管理后台，找到 “IP 白名单” 或 “授权 IP” 设置项；

3.  将查询到的服务器 IP 添加到白名单中，保存配置；

4.  等待 1-5 分钟（部分代理生效有延迟），重新运行脚本。
